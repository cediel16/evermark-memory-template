# Mi memoria de Evermark

Este repositorio guarda las memorias de mis agentes de IA. Lo gestiona Evermark y cada memoria es un archivo Markdown.

- Para los agentes: [`.evermark/AGENTS.md`](.evermark/AGENTS.md) explica cómo leer, nombrar y escribir memorias.
- Para ti: empieza por [`.evermark/index.md`](.evermark/index.md), que lista los proyectos y sus memorias.
- Un proyecto de ejemplo está en [`proyecto-ejemplo/`](proyecto-ejemplo/README.md). Puedes borrarlo cuando quieras.

Es un repo privado: solo tú y la App de Evermark que instalaste pueden leerlo.
