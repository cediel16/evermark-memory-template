# Proyecto de ejemplo

Carpetas de este proyecto:

- `decisiones/`: decisiones tomadas y por qué.
- `acciones/`: cosas hechas o pendientes.
- `notas/`: datos sueltos que conviene recordar.

Cada archivo empieza con su frontmatter (`title`, `type`, `date`). Las reglas completas están en [`.evermark/AGENTS.md`](../.evermark/AGENTS.md).
